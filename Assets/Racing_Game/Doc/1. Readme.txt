Import guide:
1. Create an empty URP project for Unity 6 or above (use LTS versions)
2. Import package completely
3. Restart unity 
4. Open the "Garage" scene and press play

Note 1: You can delete game saved data by pressing "H" key  to delete PlayerPrefs data in the editor
Note 2: You can change default settings from the "MainUtility" component attached to the Canvas gamer object in the Garage scene
_____________________________________

You can optimize game build size (50%) by reducing the texture import size
1. Open: Window->Mobile Optimizer->Batch Texture Importer
2. Use 256 texture size and High compression quality 
3. Press "Batch Import"
4. Now you can manually increate texture size for important textures (roads, terrain, ui)
5. Select road textures and set import size to 2k or 4k to increase game important textures quality
